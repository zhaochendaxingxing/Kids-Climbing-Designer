🔩 按您的思路推算「45°L 嵌套件」目标尺寸

推导骨架 = 底部框架 40 + 立杆轴心 ±20 + 斜杆 45° 交汇顶部 · 单位 cm

① 推导链条（对称，看右半 → 乘 2）

1. 底部 35 杆 + 两端各 L 件 → 立杆轴心距 = 2·(17.5+2.5) = 40，半宽 20。
2. 斜杆 bar-35，45° 水平投影 = 35·cos45° ≈ 24.75。
3. 投影 24.75 > 半宽 20，超出 Δ = 24.75 − 20 = 4.75 ≈ 4.7。
4. 按您的关系「半宽 = 斜杆投影 − 立杆偏移」：要让立杆回落到 x=20，嵌套件必须把立杆端向内收敛 X = 4.7cm（您作图已确认）。
5. 嵌套件目标横向尺寸 = 嵌套深度 X(4.7) ＋ 单个球转接直径 5 = 9.7 cm。
✅ 您的结论成立：嵌套深度 X = 4.7（舍入后，精确 Δ=4.75）。这是让 35cm 斜杆 45° 竖向投影后立杆正好落回框架角(半宽20)所需的唯一内收量。

结论：要「三角形结构与方形框架由 45°L 件完美接合」，嵌套件必须是独立的内收型构件：立杆接口相对斜杆接口向内侧偏移 X = 4.7cm（精确 Δ=4.75），整体横向尺寸 9.7cm（含 5cm 球转接段）。

现有 COMBO（两独立球嵌套）物理上无法做到内收 4.7——嵌套深度 K 上限仅 ~1.6（两球心距 5−K 不能小于球半径之和），且方向本身就是外扩。因此需要一台一体式专用件，或改斜杆长度/角度。
