# 45°L嵌套组合校准

## 绕立杆选方向

选中完整组合中的任意成员后，使用模型旁的「转 45°」按钮，以 L 件向下接口所在的竖直轴旋转整个组合。每次有效调整记录一次撤销，保留组和选择。斜杆已有连接时，若旋转会断开连接则拒绝操作。主体穿插或姿态非竖直时，界面会提示原因。

参考文件为《儿童攀爬架-屋顶.skp》，几何数据于 2026-11-17 从 SketchUp 提取。SketchUp 的 Z 轴对应网站的 Y 轴。尺寸从 mm 换算为 cm。

独立红色组件 #7 是45度件，屋顶檐口的黑色 L 件位于框架立杆顶部。右檐口45度球心位于 x=543.198mm、z=375mm，L球心位于 x=425mm、z=375mm。两球中心距118.198mm，不能使用原来的40mm中心距。

- 水平套筒外径50mm、内径40mm，从45度球面向内侧延伸68.198mm；套筒口与L件水平凸头根部对齐，凸头插入套筒。
- 斜接口向屋脊上升45°，接杆肩部距45度球心75mm，后接50mm插入段；用加长颈部表达肩部前实体。
- L件保持标准配件定义，另一接口竖直向下。
- 屋顶两根350mm斜杆配顶部L件，按檐口内收量计算立杆间距400mm，与参考底框一致。

修改数据、渲染和组合整体吸附。`src/lib/construction.ts` 集中处理组合求解和端部六通朝向。候选覆盖四个水平朝向和斜杆实际方位，竖直锚点也会搜索水平旋转。端口匹配使用精确位置与反向共轴约束，排除内部及外部已占用端口。替换必须保留原节点的全部杆件连接，因此三个以上实连杆件的六通不能替换为仅两个对外接口的组合。无合法解时保留原件。其他45度配件的套筒长度保持原值。

组合朝向在合法候选中优先匹配更多端口，并参考周围结构中心向内布置斜口。主体碰撞探针覆盖球心和斜向加长颈部，检测杆件实体长度范围内的穿插和接头球心重叠；允许凸头插入中空杆件。这是放置时的几何保护，尚不是任意复杂曲面之间的精确布尔碰撞。端部六通固定绕杆轴的滚转，以世界竖直方向确定屋顶平面，轴向竖直时保持世界轴对齐。

右键替换在求解通过后一次性更新零件、组及选中状态，只记录一次撤销快照。`scripts/check-construction.ts` 覆盖朝向、精确锚点、端部滚转、三杆节点拒绝、主体穿插和占用端口。

验证脚本 `scripts/check-combo.ts` 覆盖尺寸、嵌套端口、屋顶跨度和四向旋转。旧方案保留原有位置，没有迁移旧组合中心距；旧组合应删除后重新插入。尚需在线手动核验拖放和实际视觉。
